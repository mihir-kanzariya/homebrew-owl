# Homebrew Tap for OpenOwl

AI desktop automation MCP server — give your AI eyes and hands.

## Install

```bash
brew install mihir-kanzariya/owl/owl
```

## Usage

1. Get a license key at [license-portal-bay.vercel.app](https://license-portal-bay.vercel.app)
2. Save your key: `echo "owl-xxxx-xxxx-xxxx" > ~/.openowl/license.key`
3. Add to Claude Code MCP config and start automating

## Update

```bash
brew upgrade owl
```
